## Answers

1. `npx @backstage/create-app@latest`
2. Frontend **3000**, backend **7007**.
3. **Yarn** with **Yarn workspaces** (a monorepo).
4. **Node 22 or 24** (Active LTS).
5. `yarn build:backend` (then build with `packages/backend/Dockerfile`).
6. **Core**, **App**, **Plugins**.
7. Over **HTTP API requests** (frontend fetches from backend).
8. The built-in **proxy** service.
9. **PostgreSQL** (prod), **SQLite** (dev/test).
10. A package that adds features to a backend plugin via its **extension points**;
    it's deployed in the same backend instance as its target plugin.
11. With environment-variable substitution: `${VAR_NAME}`.
12. **`catalog-info.yaml`**.
13. `apiVersion`, `kind`, `metadata`, `spec`.
14. **`relations`** and **`status`**.
15. **`type`**, **`lifecycle`**, **`owner`**.
16. **labels** = identifying key/values for filtering; **annotations** =
    non-identifying links to external systems/tools; **tags** = free-form strings.
17. Component, API, Resource, System, Domain, Group, User, Location, Template.
18. **Domain ⊃ System ⊃ Component / Resource / API**.
19. Static **Location** in `app-config.yaml`; UI **"Register an existing
    component"**; automated **discovery / Entity Providers**.
20. **63 characters**.
21. Frontend = React UI mounted at a route in the browser; backend = Node.js
    service exposing APIs. They communicate over the network/HTTP.
22. In `packages/app/src/App.tsx` (and layout files like `EntityPage.tsx`).
    Backend plugins are added in `packages/backend/src/index.ts`.
23. **Material UI (MUI)** (plus `@backstage/core-components`).
24. **`parameters`**, **`steps`**, **`output`**.
25. `catalog:register`.
26. **camelCase** — dashes break JavaScript expression evaluation.
27. **`backstage.io/techdocs-ref`**.
28. **Generator → Publisher → Storage**.
29. **MkDocs** (configured via `mkdocs.yml`).
